# Ice Lake AVX-512 baseline — 2026-08-22

Scalar baseline collected on an AVX-512-capable Google Compute Engine host for
Phase 1. This run completes the second hardware measurement requested by issue
#9; it measures the scalar kernel on AVX-512 hardware, not the unimplemented
AVX-512 backend.

## Environment

| | |
|---|---|
| CPU | Intel Xeon Ice Lake at 2.6 GHz, 2 vCPUs |
| ISA | AVX-512F, DQ, IFMA, CD, BW, VL, VBMI, VNNI |
| VM | Google Compute Engine N2, KVM |
| OS | Ubuntu 24.04, Linux 6.17.0-1022-gcp |
| Compiler | GCC 13.3.0, optimized benchmark preset |
| Affinity | vCPU 1 |
| Frequency scaling | disabled |

The benchmark used seven randomly interleaved repetitions with a one-second
minimum sample time. The table reports medians. Serialized `RDTSC` supplied the
cycles-per-byte measurement.

## Results

| Benchmark | Throughput | Cycles/byte | Cycles/byte CV |
|---|---:|---:|---:|
| `BM_vphilox` | 0.987 GiB/s | 2.453 | 0.110% |
| `BM_vphilox_bulk` | 1.145 GiB/s | 2.115 | 0.034% |
| `BM_mt19937` | 1.845 GiB/s | 1.312 | 0.048% |
| `BM_philox_scalar` | 1.133 GiB/s | 2.138 | 0.056% |

Scalar Philox reached 0.61x the throughput of `std::mt19937` and used 1.63x
the cycles per byte. The approximately 10x reported slowdown did not reproduce.
Together with the Coffee Lake and native ARM results, this establishes that the
figure must be presented as external context rather than a vphilox result.
